# Django ORM Lab — Database Design and Query Optimization

**Course:** DTI412 — Special Topic in Application Development

## Project Overview

This project demonstrates database design, Django ORM implementation, database relationships, and query optimization using Django.

The project implements a Training Management System with employee, department, course, and training record management.

## Technologies Used

- Python
- Django 5.x
- SQLite
- Django ORM
- Visual Studio Code

## Database Models

The project includes the following models:

- **Department:** Stores department information.
- **Employee:** Stores employee details and department relationships.
- **Course:** Stores training course information.
- **TrainingRecord:** Manages employee course enrollment, completion status, and scores.
- **Category and Product:** Used for advanced ORM challenge exercises.

## Part 4 — QuerySet API and Optimization

The project demonstrates:

1. **Q Objects:** Complex conditional queries using AND (`&`), OR (`|`), and NOT (`~`).
2. **F() Expressions:** Database-side field calculations and atomic updates.
3. **select_related():** Optimizes ForeignKey queries using SQL JOIN.
4. **prefetch_related():** Optimizes Many-to-Many queries using batch fetching.
5. **SQL Inspection:** Examines SQL statements generated by Django ORM.

## Part 6 — Advanced Challenges

Four additional ORM exercises:

- Advanced conditional searches using Q Objects.
- Dynamic stock threshold alerts using F() and Q Objects.
- Atomic price updates using Case and When.
- Atomic purchase operations to prevent race conditions.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/K-tech007/django-orm-lab.git
cd django-orm-lab
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Install Django

```bash
pip install "django>=5.0,<6.0"
```

### 5. Run database migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### 6. Create an administrator account

```bash
python manage.py createsuperuser
```

### 7. Start the development server

```bash
python manage.py runserver
```

Open the following address in your browser:

http://127.0.0.1:8000/admin/
